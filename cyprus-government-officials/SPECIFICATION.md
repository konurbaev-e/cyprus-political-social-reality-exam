# Спецификация: тест по должностям правительства Кипра

## Цель

Создать учебный тест, помогающий запомнить соответствия между должностными лицами текущего правительства Кипра и занимаемыми ими должностями. Исходный набор данных — `cyprus_government_officials_greek_russian.csv` в этой же папке. Рабочая версия приложения хранит данные непосредственно в `index.html`.

## Техническая архитектура

- Приложение — одна автономная веб-страница `index.html`, открываемая прямо в браузере с локального компьютера.
- Все 34 записи встраиваются в JavaScript-код внутри `index.html`. CSV служит редактируемым исходником, но приложение не читает его при запуске; при изменении CSV встроенный массив необходимо обновить вручную.
- Фотографии хранятся локально в подпапке `photos/` (по одному файлу на каждую запись), а пути к ним заданы в `index.html` в том же порядке, что и записи. Источники изображений перечислены в `photos/photo-credits.md`.
- Для запуска не требуются локальный веб-сервер, установка пакетов, база данных, сборка, подключение к сети или сторонние библиотеки.
- Вся логика теста и состояние текущего раунда работают в браузере. Сохранение данных и результатов между запусками не требуется.
- Страница должна корректно работать при прямом открытии как локальный файл и адаптироваться к узкому экрану.
- Не использовать сетевые ресурсы и внешние шрифты: интерфейс и все фотографии должны быть доступны офлайн.
- Использовать системный стек шрифтов `"Segoe UI", Arial, "Noto Sans", sans-serif` с поддержкой греческих символов; не ставить `Inter` перед системными шрифтами. Греческие буквы, в частности «ο», должны отображаться ровно и читабельно. Разрешить браузеру синтезировать начертания `weight` и `style`, если выбранный шрифт их не содержит.

## Данные

- Ожидаемое число записей: 34 должности.
- Для каждой записи хранятся четыре значения: должность по-гречески, должность по-русски, ФИО по-гречески и ФИО по-русски.
- Пользователь может переключать язык интерфейса и вопросов между русским и греческим. В выбранном языке отображаются и вопрос, и ответы, и обратная связь.
- При старте раунда приложение проверяет встроенный набор: ровно 34 записи, все поля заполнены, значения ответов внутри каждого поля уникальны. Если проверка не пройдена, показать понятную ошибку и не начинать раунд.
- Каждый вопрос и вариант ответа строится из встроенных записей; правильная пара «ФИО — должность» сохраняется для обратной связи.

## Режимы

1. **Должность → ФИО.** Вопрос: «Кто занимает должность: [должность]?» Варианты ответа — четыре ФИО.
2. **ФИО → должность.** Вопрос: «Какую должность занимает [ФИО]?» Варианты ответа — четыре должности.

В интерфейсе должно быть понятно, какой режим и язык отображения выбраны. Варианты ответа должны быть однозначными в рамках раунда.

- В режиме **Должность → ФИО** рядом с каждым вариантом ФИО показывается небольшая локальная фотография соответствующего человека.
- В режиме **ФИО → должность** фотографии не показываются, так как варианты ответа — должности.
- Отсутствие сети не должно мешать загрузке фотографий; изображения должны лежать рядом с `index.html` в `photos/`.

## Правила раунда

- Один полный раунд включает все 34 записи ровно по одному разу; ни одна запись не пропускается и не повторяется.
- Порядок вопросов случайный и заново перемешивается при каждом запуске раунда.
- Для каждого вопроса правильный ответ берётся из целевой записи, а три неверных варианта случайно выбираются из других записей.
- Все четыре варианта ответа перемешиваются; правильный ответ не должен постоянно занимать одну позицию.
- Вопрос отображает текущий номер и общее число вопросов (например, «7 из 34») и прогресс раунда.

## Обратная связь и завершение

- После выбора ответа сразу показать, верен ли ответ.
- Показать правильную пару «ФИО — должность», в том числе если пользователь ответил неверно.
- Затем дать перейти к следующему вопросу.
- В конце раунда показать результат: число правильных ответов из общего числа вопросов и список вопросов, на которые пользователь ответил неверно, с правильными парами.
- Предусмотреть действие **«Повторить ошибки»**, запускающее раунд только по ошибочным записям с теми же правилами четырёх вариантов ответа. Если ошибок нет, сообщить об этом и не запускать пустой раунд.
- Предусмотреть запуск нового полного раунда и выбор любого из двух режимов.

## Критерии приёмки

- Пользователь может выбрать любой из двух режимов и язык отображения; оба доступны без сети.
- Страницу можно открыть напрямую как локальный `index.html`; сервер и установка зависимостей не нужны.
- Все 34 локальные фотографии загружаются без сети и соответствуют записям в массиве officials.
- В режиме «Должность → ФИО» у каждого варианта имени отображается фотография; в режиме «ФИО → должность» фотографий нет.
- Греческий текст, включая «ο», читаем в выбранном системном стеке шрифтов; внешняя загрузка шрифта не требуется.
- Все 34 встроенные записи соответствуют исходному CSV по четырём полям.
- Полный раунд содержит каждую из 34 записей ровно один раз, а порядок вопросов перемешан.
- На каждом вопросе ровно четыре ответа: один правильный и три варианта из других записей; их порядок перемешан.
- После ответа видны результат выбора и правильная пара ФИО/должность.
- По завершении показаны счёт и ошибки; ошибочные записи можно пройти повторно.
- При некорректном встроенном наборе данных пользователь получает понятное сообщение.

## За пределами первой версии

- Таймер, рейтинги, учёт нескольких пользователей и сохранение истории результатов не требуются.
- Проверка и актуализация того, кто занимает должности на текущую дату, выполняется отдельно от логики теста; приложение использует записи, встроенные в `index.html` и обновляемые по CSV.
